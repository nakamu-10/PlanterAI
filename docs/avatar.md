# 3D アバターの作り方

カラ美の 3D
アバター（`app/public/models/karami.glb`）を作ったときの手順と、ハマったところをまとめる。ほかの植物のアバターを作るときは、ここの「アプリとの約束ごと」を守れば、アプリのコード（`app/src/karami3d.js`）を変えずに差し替えられる。

## ファイル

| ファイル                       | 中身                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| `app/models-src/karami.blend`  | 元データ（Blender 4.2）。モデル・骨・動き・下のスクリプトが入っている                     |
| `app/models-src/scripts/*.py`  | `karami.blend` の中のテキスト（スクリプト）を書き出したもの。Blender なしで読むための写し |
| `app/public/models/karami.glb` | アプリが読む書き出し結果（約930KB）                                                       |
| `app/src/karami3d.js`          | glb を読んで表示し、動きを混ぜる                                                          |
| `app/src/mood.js`              | 気分と土の水分から、しおれ・元気のなさ・涙の量（0〜1）を出す                              |

### ほかの植物のアバター

骨と動きはカラ美のものをそのまま使い、見た目だけを置き換える。アプリは鉢の
`plant_profile` で glb を選ぶ（`app/src/home.logic.js` の `MODELS`）。

| 植物             | 作り方                                                                                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| サボテン         | `karami.blend` を開き、`scripts/cactus_build.py` を流して `cactus.blend` に保存し、`cactus.glb` に書き出す                                                  |
| エバーフレッシュ | `cactus.blend` を開き、`scripts/everfresh_build.py` を流して `everfresh.blend` に保存し、`everfresh.glb` に書き出す。頭・体・目の作りはサボテンから引き継ぐ |

エバーフレッシュは、いつも目の上半分をまぶたで覆う（眠たがり）。まぶたの骨（`lid_*`）は縮めると頭の中へ沈む作りで途中で止められないので、半分のまぶたは目の骨に付けた別のパーツ（`SleepyLid_*`）にしている。羽のような葉はもとから垂れているので、しおれ（`Wilt`）で葉を回す角度をカラ美より小さくしている。肩と背中のマントは、羽のような葉をマントの骨（`cape_*`）に付けたもの。枕を抱えたままにするため、どの動きでも腕の振りをカラ美の15%に抑えている。

スクリプトの正本は `karami.blend` の中のテキスト。Blender
で書き換えたら、下の「スクリプトを書き出す」で `scripts/` も更新する。

## アプリとの約束ごと

`karami3d.js` は、glb の中の名前を決め打ちで探す。足りないと例外を投げて 2D
の画像に切り替わる。

### 動き（Action）

| 名前       | 長さ（24fps） | 流し方                                                    |
| ---------- | ------------- | --------------------------------------------------------- |
| `Idle`     | 48            | 常に流す。元気なときの待機                                |
| `Wilt`     | 48            | 常に流し、`Idle` と重みで混ぜる。しおれ                   |
| `Joy`      | 30            | 1回だけ。水やり・`cheer()`                                |
| `Surprise` | 16            | 1回だけ。つつく・着地                                     |
| `Pet`      | 38            | 1回だけ。なでる                                           |
| `Struggle` | 12            | 持ち上げている間くり返す（#24）                           |
| `Cry`      | 48            | 常に流す。涙の骨（`cry_*`・`tear_*`）のトラックだけを使う |

### 骨とメッシュ

| 名前                     | 役目                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| `leaf_*`・`cape_*`（骨） | 土の水分でしおれる部分。`Idle` と `Wilt` のうち、この骨のトラックだけを土の水分の重みで混ぜる |
| ほかの骨                 | 気分（元気のなさ）の重みで混ぜる                                                              |
| `cry_L`・`cry_R`（骨）   | 涙と目のうるみの親。アプリが大きさを変えて出し入れする                                        |
| `tear_*`（骨）           | 頬を流れる涙。`Cry` の中で動かす                                                              |
| `HeadMesh`（メッシュ）   | 頭。画面のどこから上が頭か（なでる／回すの分かれ目）をこの位置で決める                        |

名前の前置き（`leaf_`・`cape_`・`cry_`・`tear_`）で振り分けているので、葉の枚数や涙の数は植物ごとに変えてよい。

### 向きと大きさ

- 正面は −Y、上は +Z。足元を原点に置く
- カラ美は高さ約0.95。カメラ（`karami3d.js`）はこの高さに合わせてあるので、大きく違うならカメラも直す

## Blender での手順

カラ美は Claude Code から MCP（Blender の中で Python
を動かす）で作った。手で作っても、約束ごとが同じならよい。

1. イラストを正面から見て、頭（楕円体）・胴・腕・足・葉を作る。顔のパーツは、イラストの画像座標の輪郭を頭の表面に貼る（`karami_face.py`
   の `decal`）
2. 葉は1枚ずつメッシュを作り、付け根に骨を置く（`karami_lib.py`・`karami_build.py`）。骨の局所
   X を「しおれる軸」にしておくと、動きを作るとき楽になる
3. 葉の模様はテクスチャを計算で描く（`karami_tex.py`）
4. 表情は、パーツを差し替えて出す。笑い目・まぶた・開いた口・への字口・涙は別のメッシュにし、それぞれの骨の大きさを
   0.001 にして隠し、使う動きの中だけで 1
   にする（`karami_expr.py`・`karami_cry.py`）
5. 動きは `karami_anim.py`
   の関数（`rot_world`・`droop`・`key`・`new_action`・`smooth`）で、キーを打って作る。例は
   `karami_struggle.py`

`Idle`・`Wilt`・`Joy`・`Surprise`・`Pet`・`Cry`
を作ったスクリプトは、その場で流しただけで `karami.blend`
に残していない。作り直すときは `karami_struggle.py` を手本にする。

### glb に書き出す

```python
bpy.ops.export_scene.gltf(
    filepath=r"...\app\public\models\karami.glb",
    export_format="GLB",
    export_animation_mode="ACTIONS",  # 動きを1本ずつ別のクリップにする
    export_force_sampling=True,
    export_def_bones=False,
)
```

書き出したら、`karami3d.js` の `MODEL_URL` の `?v=`（#24
で入れた）を1つ上げる（下の「ハマったところ」）。

### スクリプトを書き出す

Blender の Python コンソールか MCP で流す。

```python
import bpy, os
out = r"...\app\models-src\scripts"
for t in bpy.data.texts:
    with open(os.path.join(out, t.name + ".py"), "w", encoding="utf-8", newline="\n") as f:
        f.write(t.as_string().rstrip("\n") + "\n")
```

### 確かめ方

- Blender
  で一時的なカメラを置いて、正面・斜め・横から描画して見る（終わったらカメラは消す）
- 全部の動きの全コマで、腕がマントを突き抜けないかを見る
- `npm --prefix app run dev` で `/app/?emotion=不安&moisture=20&debug`
  を開き、コンソールから `karami.cheer()` などで動きを流す。`emotion` と
  `moisture` で、しおれと涙の具合を固定できる

## ハマったところ

- **顔のパーツが全部出る**：1回だけの動きが終わるフレームで、動きの重みの合計が
  1 を切ると、three.js が足りない分を初期ポーズ（全部の骨の大きさが
  1）で埋める。隠していた笑い目や涙が一瞬全部出る。アプリは1回だけの動きの重みを自前で上げ下げし、終わったら最後の姿勢のまま下げきる（`clampWhenFinished`）
- **涙が全部の動きに入る**：glb
  の書き出しでは、全部の動きに全部の骨のトラックが入る（止まったままのトラックも）。涙の骨のトラックを混ぜると流れる距離が縮むので、アプリは
  `Cry` 以外から `cry_*`・`tear_*` のトラックを外す（#20
  で書き出しの側から直す予定）
- **目を縦につぶすと黒目まで楕円になる**：目を細める表情は、目を縮めずに「∩」の笑い目やまぶたのパーツに差し替える
- **腕がマントを突き抜ける**：腕の付け根がマントの下にあるので、腕を横に上げると脇から突き抜ける。腕は前へ上げる（前へ最大68度、外へ最大8度）
- **マントが体を突き抜ける**：体の外形を高さと角度ごとに測り、その外側に沿わせて作る（`karami_cape.py`
  の `body_hull`）
- **古い glb がキャッシュに残る**：glb を差し替えても、端末に古い glb
  が残り、足した動きが無いと 2D に落ちる。`MODEL_URL` の `?v=` を上げる
- **しおれでマントが胸の前に上がる**：マントの付け根を胸のしずくに移したため。しおれではマントを動かさない

## ほかの植物を足すとき

- 約束ごとの名前を同じにすれば、`karami3d.js` と `mood.js` はそのまま使える。glb
  のファイル名だけを植物ごとに替える
- 植物ごとの差（葉の枚数、マントの有無、背の高さ）は、前置きで振り分けているので問題になりにくい。背の高さが大きく違うときだけ、カメラを直す
- 時間がないときは、3D をやめて 2D の画像（`karami.js` の
  `setup2d`）で表示することもできる
