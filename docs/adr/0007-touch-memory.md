# 0007 アプリで触ったことを記録し、返事で触れる

- 日付：2026-11-06

## 背景

アプリでカラ美をつつく・なでる・持ち上げると、画面の中で定型文がすぐに出る。
ただ、そのことはどこにも残らず、あとで LINE
やアプリで話しかけても、カラ美は触られたことを知らない。
「さっきつついたでしょ」と言えると、画面の中と会話がつながる。

## 決定

- 触ったことを `touch_logs` に1回ごとに1行入れる（`poke`・`pet`・`lift`）
- 記録は、鍵の要る `app-data` の `touch`
  だけが受ける。本番の公開画面（鍵なし）では記録しない
- 返事を作るとき（LINE
  とアプリの両方。`_shared/conversation.ts`）に、直近6時間の記録を「つつかれた（3回、最後は10分前）」の形でプロンプトに入れる。
  毎回は触れないよう指示する
- つついたときの画面の反応は、今のまま即時の定型文にする（生成を待たない）
- 植物から自分で送る通知には入れない

## 理由

- 鍵なしで書けるようにすると、誰でも記録を増やせる。見学会で来場者が触ったことまで覚えるかは魅力があるが、回数の上限などを作る時間が機能凍結（11/10）までに無い
- 返事のプロンプトに入れるだけなら、会話の流れは今のまま変わらない
- 6時間より前に触られたことを持ち出すと、話が古くて不自然になる

## 代替案

- 公開画面でも記録する：来場者のタッチも覚えられるが、荒らしを防ぐ仕組みが要る。ログイン（ADR
  0003）を作るときに考え直す
- つついたときの反応を毎回 Gemini
  で作る：待ち時間が出て、触ったときの気持ちよさが落ちる
