# 0018 キャラを、光を焼き込んだ部屋の中に置く

- 日付：2026-11-24

## 背景

- アプリを開くたびに変化を付けて、開いてもらうきっかけにしたい（#98）。何もない背景の上のキャラだけでは、変えられる所が少ない
- 部屋には、時刻で変わる部品や、触ると何かが起きる家具を、あとから足していきたい
- スマホで動かすので、部屋の光をその場で計算すると重い

## 決定

- 部屋は Blender で作り、光を1枚の絵（2048px）に焼き込んだ glb
  にする（`app/public/models/room.glb`）。.blend
  と焼き込みのスクリプトは、リポジトリの外（`PlanterAI-room/`）に置く
- 部品の名前で役目を分ける
  - 材質
    `baked`：焼いた部分。光を当てず、焼いた絵をそのまま出す（`MeshBasicMaterial`、`toneMapped: false`）
  - `dyn_*`：時刻などで変える部品。焼かずに、ふつうの材質のまま光を当てる
  - `spot_*`：キャラの立ち位置。子の `<spot>_look` が向く先
  - `nav_floor`・`block_*`：歩ける床と障害物の目印。アプリでは外す
  - `img_*`：アプリが絵を貼る面
- 触ったときの役目は、Blender のカスタムプロパティ `touch` に書き、glb の extras
  で渡す（`calendar` など）。アプリは触った部品から親をたどって役目を読む
- カメラは正射影にし、部屋を焼いたときと同じ斜めの向きから、12°だけ見下ろす。スマホではキャラのまわりだけを写し、横にスワイプして見回す
- キャラの色の調子は Neutral のトーンマッピングでそろえる
- 居場所（#98 の段階2、11/26 に追記）
  - `spot_*` は、そこでとるポーズをカスタムプロパティ `pose`
    に持つ（`stand`・`look_up`・`sunbathe`・`sit`・`sleep`）
  - 気分・時刻（日本時間）・訴えから、上から順に見て最初に当てはまった所にいる（`chooseSpot`）：不安・苛立ちは真ん中、22〜6時はベッド、昼に日照不足で満足でなければ窓辺、昼に満足なら日だまり、昼のそれ以外は真ん中、18〜22時はソファ
  - つらいときを一番上にするのは、寝ていて気づけないことがないようにするため
  - 座る・寝るの動き（`Sit`・`Sleep`）が glb
    に無いうちは、ソファやベッドの上に立たせず真ん中にいる
  - ベッドでは横向きに寝て、肩まで布団をかぶる（11/26）。カメラは足元の斜め前から見るので、体を出したままだと足の裏ばかりが見える。布団の中の手足とマントは隠す
  - ソファでは腰を下ろして座る（11/26）。座る動きは根元と脚だけを入れ替え、顔・頭・葉は待機・しおれのまま動かす。夕方（18〜22時）も、しおれや涙で気分が分かるようにするため
  - 座っている・寝ている所を触ると立ち上がってから反応し、10
    秒さわられなければ戻る。横になったまま反応の動きを流すと、急に立ち上がって見える

- 歩く道（#98 の段階4、11/26 に追記）
  - `nav_floor` と `block_*`
    は、上から見た四角として読む。家具はキャラの半径（0.2m）だけ広げ、その角をたどる最短の道を探す（`walk.logic.js`
    の `planPath`）
  - ソファやベッドの立ち位置は家具の中にあるので、いちばん近い縁の外の床まで歩き、そこから上がる（`approachPoint`）。壁の側の縁へは出さない
  - 道が見つからないときは、まっすぐ向かう。家具をすり抜けても、動けなくなるよりよい
  - 開いたときは歩かずに、最初から居場所にいる。開いている間に居場所が変わったら、歩いて移り、画面もついていく
  - 歩く動き（`Walk`）は、座ると同じく根元と脚だけを入れ替える。しおれたまま歩けるようにするため。しおれているほどゆっくり歩く
  - 家具の上の居場所では、立ってから跳び下り、行き先の家具には手前から跳び上がる。座る・寝るのポーズは、向く先を向いてからとる
  - 持ち上げている間と、1回だけの動き（喜ぶなど）の間は、その場で止まる
  - 機嫌のよいときは、立ち位置のまわり（0.6m まで）を 15〜30
    秒おきにうろうろ歩き、3
    秒いて戻る（#149）。真ん中か日だまりに立っていて、涙が出ていないときだけ。座る・寝る・日照不足の窓辺・不安・苛立ちでは、訴えやポーズが見えなくならないよう歩かない。画面はついていかず、部屋を横に動かせるままにする
  - 前に見てから6時間以上たっていたら、部屋の右の外から居場所まで歩いてきて、機嫌がよければ喜ぶ（#149）。前に見ていた時刻は、鉢ごとに端末に覚える。開いたときに加えて、裏へ回したアプリが見えなくなったときにも残し、戻ったときにも見る。初めて開いたときと、`?emotion=`
    などの練習では迎えない
  - 部屋は奥と左が壁なので、開いている右の縁の外から入る。広い画面で部屋が全部写っていても、写っていない所から歩き出す。外から床の縁までは、家具にかからない奥行きを選ぶ（奥にはタンスがある）
  - 涙が出る機嫌のときは喜ばない。喜ぶと涙が引っ込み、訴えが見えなくなるため

## 理由

- 焼いた絵なら、光の計算はほぼいらない。glb は 630KB で、キャラの
  glb（0.9〜1.5MB）より軽い
- 名前で役目を分ければ、Blender
  で部品を足すだけで、アプリのコードを変えずに増やせる
- 正射影なら、スワイプしても家具の形がゆがまず、焼いたときの絵と合う
- 見下ろしを焼いたときの 26°
  のままにすると、正面から見ていた前の構図より顔が見えにくかった
- three.js の AgX には Blender の High Contrast
  に当たる設定がなく、キャラの色が抜けてくすんだ。Neutral
  なら色を保ったまま、明るい所を柔らかく落とせる

## 代替案

- 部屋の光をその場で計算する：影や照り返しを出すと、スマホでは重い
- 部屋全体を1画面に写す：スマホの縦長の画面では、キャラが小さすぎる
- 透視投影のカメラ：スワイプすると家具の形が変わり、焼いた絵とずれる
- 部屋を 2D の絵にする：キャラが奥と手前を行き来したり、家具に座ったりできない
