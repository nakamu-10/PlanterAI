# 0021 ホーム画面から開いたアプリは、全画面で出す

- 日付：2026-11-27

## 背景

- ホームは部屋を画面いっぱいに出す（0020）。ただ、iPhone の Safari
  で開くと、縦向きの一番上の帯（時刻など）は Safari
  が使い、ページはその裏に描けない。帯と部屋の間に切れ目が出ていた
- Safari
  で開いたときは、部屋の上の端を帯と同じ壁の色からぼかして、切れ目を目立たなくした（#172）。それでも帯の所に部屋は出ない
- アプリは、サイトの
  manifest（`display: browser`）を読んでいた。ホーム画面に追加したアイコンから開いても、Safari
  の画面のまま開いていた

## 決定

- アプリ用の manifest を `app/public/manifest.webmanifest`
  に置く。`display: standalone`、`start_url` と `scope` は
  `/app/`。アプリの4つのページは、これを読む
- 4つのページに `apple-mobile-web-app-status-bar-style: black-translucent` と
  `viewport-fit=cover` を付け、ホーム画面から開いたときは帯の裏まで描く
- ホームは部屋を帯の裏まで描く。ほかのページ（数値・記録・設定）は、帯とノッチの分だけ中身を内側へ寄せる

## 理由

- ホーム画面から開くと、帯の裏まで描ける。部屋が本当に画面いっぱいになる
- Safari
  のタブで開いたときの見え方は変わらない。サイトから選んで入る人は、今までどおり使える

## 代替案

- Safari で開いたまま帯の裏に描く：Safari ではできない
- 帯を白くして部屋と分ける（`default`）：部屋が帯の下で切れて見えるのは変わらない

## 気をつけること

- `black-translucent`
  では、帯の文字が白になる。ホームでは明るい壁の上に白い文字が乗る
- アイコンから開くと、`?pot=`
  が付かないのでカラ美のホームが開く。ほかの鉢は「∨」で選ぶ
- アイコンは、追加し直さないと新しい manifest を読まないことがある
- 設定のページの公式サイトへのリンク（`/index.html#pots`）は `scope`
  の外なので、全画面で開いていても Safari
  の小さな画面で開く。アプリの外へ出るリンクなので、それでよい
