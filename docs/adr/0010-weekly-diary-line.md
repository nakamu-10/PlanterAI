# 0010 週の LINE に、日記の絵と文を並べる

- 日付：2026-11-07

## 背景

ADR 0009 では、週の LINE
を文字だけの定型文にした（絵の数え方とリンク）。もともとの案は「7日分の絵とひとことを、LINE
にまとめて1通」だった。文字だけだと、リンクを開かないと絵も文も見えず、せっかく描いた絵が
LINE に届かない。

## 決定

- LINE の Flex Message
  のカルーセルで、1日1枚のカード（絵・日付・文）を古い順に並べ、1通で送る
- カードの絵は JPEG（720×480）を `app/public/images/diary/`
  に置く。記録のページは今の WebP のまま
- カードを LINE に断られたら、今までの定型文を送る

## 理由

- LINE の画像は JPEG か PNG だけで、WebP を受け付けない
- LINE
  の通数は送る相手の数で数えるので、カードを7枚並べても1通で、今までと変わらない
- 文は会話の中身を使っていない（ADR
  0009）うえ、送り先は鉢を結んだ本人だけなので、そのまま出してよい
- 開発の環境に LINE
  のトークンが無く、実物で試してから出せない。形が間違っていても、その週の知らせは届くようにした

## 代替案

- 絵を1枚ずつ画像で送る：1回で送れるのは5件までなので、7日分だと2回に分かれて2通になる。トークの画面も絵で埋まる
- 7日分を1枚の画像にまとめる：絵が小さくなり、文も読めない。週ごとに画像を作る処理も要る
- 記録のページも JPEG にする：同じ絵で今より重くなるので、ページのためにならない
- Vercel の画像変換で WebP を JPEG
  にする：絵は10枚で増えないので、変換の設定を増やすほどではない
