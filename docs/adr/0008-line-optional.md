# 0008 LINE と結ぶかを、鉢ごとに選べるようにする

- 日付：2026-11-06

## 背景

`devices.line_user_id` が必須で、鉢ごとに LINE の相手が1人ずつ要った。 1人の
LINE に2鉢を結ぶと返事が返らない（#34）ので、3鉢に増やすには3人の LINE が要る。

アプリのモック（#36）では、LINE
と結ぶかは任意で、アプリだけでも植物と過ごせる作りにしている。

## 決定

- `line_user_id` を任意（null を許す）にする
- LINE と結んでいない鉢は、通知（状態の変化と、15時の日照）を LINE
  に送らない。セリフは今までどおり `conversation_logs`
  に残すので、アプリの吹き出しに出る
- LINE からの返事（`line-webhook`）は、結んだ鉢だけが受ける（今までどおり）

## 理由

- 展示で3鉢に増やすときに、LINE の相手を3人そろえなくて済む
- セリフを作って残すところは変えないので、アプリでは LINE
  と結んだ鉢と同じように見える

## 代替案

- 1人の LINE で複数の鉢を扱う（#34）：LINE
  で話しかけたときに、どの鉢への言葉かを決める仕組みが要る。凍結のあとに回す
- LINE と結ばない鉢ではセリフを作らない：Gemini
  の呼び出しは減るが、アプリの吹き出しが更新されなくなる
