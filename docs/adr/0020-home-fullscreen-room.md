# 0020 ホームは、部屋を画面いっぱいに出す

- 日付：2026-11-27

## 背景

- ホームは、上から名前・鉢の切り替え・「キャラ／数値」の切り替え・気分と水やりの欄が並び、部屋はその下の残りに出ていた。スマホでは、部屋が画面の半分ほどしかなかった
- 部屋の中でキャラが暮らす（0018）ようにしたので、部屋の見える所を広くしたい

## 決定

- 部屋の 3D
  を、画面の上の端から下のシートの裏まで出す。名前・日数・右上のボタンは、部屋の上に重ねる
- 気分・次の水やり・最後の水やりと、話しかける欄と、触り方の案内は、下の1枚のシートにまとめる。シートは部屋の下の端に少し重ね、丸めた角から部屋が見えるようにする
- 「キャラ／数値」の切り替えはやめ、右上に数値の画面を開くボタンを足す
- 公式サイトへ戻るリンク（#122）は、設定のページへ移す
- 写す中心を、立ち位置から 1.15m の高さにする（前は
  0.95m）。部屋が縦に長くなったので、キャラを下に寄せ、足元をシートのすぐ上に置く
- 鉢の切り替えを名前の横の「∨」にすることと、シートを引き上げて広げることは、別の
  PR で入れる

## 理由

- 中村が見本の画像で示した配置に合わせた
- 部屋の床と壁は外へ延ばしてある（0019）ので、画面を広げても切り口は写らない
- 写す高さ（2.8m）は変えない。見本の画面の高さに対するキャラの大きさは、今の値でほぼ合っていた

## 代替案

- シートを重ねず、部屋の下で切る：見本では、シートの角から部屋が見えている
- 「キャラ／数値」の切り替えを部屋の上に重ねる：部屋の上に置く物が増え、部屋を見る広さが減る
