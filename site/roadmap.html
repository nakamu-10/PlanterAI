ROADMAP

今後の展望

LINEから届く言葉と、プランターに浮かぶ表情。ここまでは、すでに実機で動いています。次につくるのは、通知を待つだけではなく、こちらからカラ美に会いにいける体験です。

いまできること

センサーで測り、状態を判断し、カラ美の言葉に変えてLINEへ届ける。こちらから話しかければ会話が続き、OLEDにも表情が現れます。この一連の動作までは実装済みです。

実装済
LINE通知とOLEDの表情
センサー計測から状態判定、言葉の生成、LINE通知、OLED表示まで動作します。
実装済
双方向の会話
こちらから話しかけると、カラ美が応答します。状態は判定し直さず、すでに確定した内容だけを参照します。

現在の技術構成

Arduino Supabase Gemini LINE Messaging API

次につくるもの

次に取り組んでいるのは、カラ美と直接触れ合える専用アプリです。LINEが異変を受け取る場所なら、アプリは用事がないときにも会いにいける場所。通知を見るだけだった関係を、こちらから関われるものへ広げます。

使い続けるために

機能を増やすだけでは、日常で使える製品にはなりません。防水、センサーのずれ、運用コストには、まだ解かなければならない課題があります。

屋外で使える防水へ

防水はプロトタイプの段階で、屋外への常設には対応していません。

センサーのずれを抑える

土壌水分センサーにはADCドリフトがあり、長く使うには定期的な校正が必要です。

運用コストを下げる

LLM APIの運用コストも課題です。通知回数を抑える設計は、コスト削減にもつながります。

調査対象を広げる

調査の回答者83名は10代と20代が80%、学生が76%を占めています。回答者に偏りがあるため、一般消費者全体には当てはめられません。

通知回数を抑える設計や異常値を捨てる処理を重ねながら、無理なく使い続けられる形に近づけていきます。
